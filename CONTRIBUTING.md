# Contributing / Contribuir

We welcome contributions from humans and AI-assisted authors. Unlike yt-dlp's own upstream contribution policy, **this independent repository permits AI-generated patches**.
Contributors remain responsible for correctness, licenses, security and disclosure.

- Open an issue describing the bug or feature with sanitized details.
- Submit small PRs with regression tests and the command output you actually observed.
- Clearly disclose use of AI assistance in the PR description.
- Never include access tokens, session cookies, private media or third-party copyrighted test files.
- Never claim a platform is supported merely because an extractor name exists.
- No bypass of DRM, private material, authentication barriers or usage limits.
- Report security vulnerabilities privately (see SECURITY.md).

Project-authored code is MIT licensed. Upstream dependencies retain their own licenses.
